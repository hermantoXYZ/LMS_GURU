Konfigurasi Backend Google Apps Script & Spreadsheet

Salin skrip di bawah ke Google Apps Script untuk membuat 6 tabel database otomatis

Untuk permanen saat di-deploy ke Vercel, masukkan URL Web App Anda langsung ke variabel const GAS_WEBAPP_URL = '...' di dalam file index.html (atau uji coba sementara di bawah ini).

Langkah 1

Buka sheets.new di browser untuk membuat Google Spreadsheet baru. Klik menu Ekstensi > Apps Script.

Langkah 2

Hapus kode bawaan, tempel kode Code.gs di bawah, lalu jalankan fungsi setupDatabase() sekali untuk membuat ke-6 sheet & akun default.

Langkah 3

Klik Terapkan > Deployment Baru > Aplikasi Web. Akses: Siapa saja (Anyone). Salin URL Web App dan tempel di atas.
